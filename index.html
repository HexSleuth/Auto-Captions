How the internal listener works. The Web Speech API only listens to the microphone. Two ways to route system audio:

  1. Virtual cable (recommended). Install VB-CABLE (Win), BlackHole (macOS) or module-null-sink (Linux). Pick the cable in Monitor output and set it as OS default mic.
  2. Speakers → mic. Capture a Chrome tab with Share tab audio ticked and keep monitor audible.
