System / Tab audio → Whisper (In-browser)

Capture any tab or the whole screen (with audio), and transcribe it live using Whisper running in a Web Worker. No virtual cable, no monitor loop, no API key. First run downloads the model (~40 MB for tiny.en), then it's cached.

How it works: getDisplayMedia({audio:true}) → 16 kHz PCM via ScriptProcessorNode → sliding 9 s window → Whisper worker every ~3 s → only newly appearing content is emitted. No monitor playback, so no echo loop.
