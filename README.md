<h2 align="center">📖 What is Auto Captions?</h2>

<p align="center">
  <b>Auto Captions</b> is a fully client-side captioning studio. It turns <b>microphone</b>, <b>tab/system audio</b>, or an <b>uploaded media file</b> into accurate transcripts and production-ready subtitle files — <i>without a single API key, upload, or backend server</i>.
  <br/><br/>
  Speech recognition runs locally via <code>@xenova/transformers</code> (Whisper) inside a <b>Web Worker</b>, while live microphone captions use the <b>Web Speech API</b> for instant, zero-download results.
</p>

<div align="center">
  <table>
    <tr>
      <td align="center">🔐<br/><b>Private</b><br/><sub>Nothing leaves your machine</sub></td>
      <td align="center">🔑<br/><b>Keyless</b><br/><sub>No API keys, ever</sub></td>
      <td align="center">🌐<br/><b>Offline-capable</b><br/><sub>After model cache</sub></td>
      <td align="center">🎬<br/><b>Karaoke</b><br/><sub>Word-level timing</sub></td>
      <td align="center">📦<br/><b>Multi-format</b><br/><sub>SRT · VTT · ASS · WAV</sub></td>
    </tr>
  </table>
</div>

> [!IMPORTANT]
> **Secure context required.** The app must be served over `https://` or `http://localhost`. GitHub Pages is HTTPS, so you're fine — `file://` **will not work**.

<h2 align="center">🎙️ Three Ways to Caption</h2>

| Mode | Source | Engine | Speed | Best For |
|:-----|:-------|:-------|:------|:---------|
| **🎤 Microphone** | `getUserMedia` | Web Speech API | ⚡ Instant | Meetings, dictation, live notes |
| **🖥️ System / Tab** | `getDisplayMedia` + audio | Whisper (Web Worker) | 🐢 Model-bound | Recording calls, streams, videos |
| **📁 File Upload** | `<input type="file">` / drag-drop | Whisper (Web Worker) | 🐢 Model-bound | Existing videos, podcasts, lectures |

> [!TIP]
> **If `getDisplayMedia` is unavailable** (e.g. some Firefox builds), pick the **Microphone** source — same capture → WAV → Whisper → export pipeline, just a different input.

<h2 align="center">🧠 How the Pipeline Works</h2>

<div align="center">

```text
┌──────────┐    ┌─────────────────────┐    ┌──────────────┐
│  Source  │───▶│  Capture (PCM)      │───▶│  WAV chunks  │
│  Mic /   │    │  @ native rate      │    │  (~10 s ea.) │
│  Tab /   │    └─────────────────────┘    └──────┬───────┘
│  File    │                                      │
└──────────┘                                      ▼
                                     ┌────────────────────────┐
                                     │  Whisper (16 kHz)      │
                                     │  sliding 9 s window    │
                                     │  ⚙️ Web Worker         │
                                     └───────────┬────────────┘
                                                 ▼
                                     ┌────────────────────────┐
                                     │  Export                │
                                     │  SRT · VTT · ASS · WAV │
                                     └────────────────────────┘
```

</div>

<details>
<summary><b>🔍 Pipeline details (click to expand)</b></summary>

<br/>

1. Source selection — the app picks between getUserMedia (mic), getDisplayMedia (tab/screen with audio), or a user file.
2. PCM capture — audio is captured through the Web Audio API at its native sample rate, so nothing is lost to an early resample.
3. Chunking — the stream is sliced into ~10 second WAV chunks for both streaming transcription and archiving.
4. Whisper inference — chunks are resampled to 16 kHz and fed to Whisper inside a Web Worker using a sliding 9-second window so captions stay near-realtime without blocking the UI.
5. Export — transcripts are serialized to SRT / VTT / ASS (with word-level karaoke tags) while the WAV chunks remain downloadable individually or as a full session archive.

</details>

<h2 align="center">⚡ Quick Start</h2>

1️⃣ Use it instantly (no install)

👉 

2️⃣ Run it locally

```bash
# Clone
git clone https://github.com/HexSleuth/Auto-Captions.git
cd Auto-Captions

# Serve over localhost (REQUIRED — file:// will not work)
python -m http.server 8000
#   or
npx serve .
```

Then open .

[!WARNING]
Opening index.html directly via file:// disables getUserMedia, getDisplayMedia, and Web Workers. Always serve over http://localhost or https://.

3️⃣ First run tips

· 🎤 Mic tab → click Start listening, allow the microphone prompt.
· 🖥️ System tab → click Capture & transcribe, pick a tab, and tick “Share tab audio.”
· 📁 File tab → drop a media file and let Whisper warm up (first model download is cached).

<h2 align="center">🎨 ASS Styling & Karaoke</h2>

The Preview & Karaoke panel plays your file and renders the word-level animated caption exactly as it will appear in the ASS export — so what you see is what you burn in.

The style controls mirror the Python build_ass generator, letting you tune:

· 🔤 Font family, size, and weight
· 🎨 Primary, secondary, and outline colors
· 🖊️ Outline & shadow thickness
· 📐 Alignment and margins
· ✨ Karaoke word-highlight timing

<h2 align="center">🔒 Privacy Model</h2>

<div align="center">

```text
   ┌──────────────────────────────────────────┐
   │            YOUR BROWSER                  │
   │                                          │
   │   🎤 Mic ──┐                             │
   │   🖥️ Tab ──┼──▶ Web Worker ──▶ Captions  │
   │   📁 File ─┘       (Whisper)             │
   │                                          │
   │   ❌ No uploads   ❌ No API keys          │
   │   ❌ No server    ❌ No tracking          │
   └──────────────────────────────────────────┘
```

</div>

· Nothing leaves your machine. All audio processing and inference happens client-side.
· The model is fetched once from a CDN and cached by your browser — after that, it works offline.
· No accounts, no keys, no telemetry.

<h2 align="center">❓ FAQ</h2>

<details>
<summary><b>Do I need an API key?</b></summary>
<br/>
No. There are no API keys anywhere in the project. Everything runs in your browser.
</details>

<details>
<summary><b>Why doesn't it work when I open the HTML file directly?</b></summary>
<br/>
Browsers only expose <code>getUserMedia</code>, <code>getDisplayMedia</code>, and Web Workers in a <b>secure context</b>. Serve the app over <code>https://</code> or <code>http://localhost</code>. GitHub Pages is already HTTPS.
</details>

<details>
<summary><b>Is my audio uploaded anywhere?</b></summary>
<br/>
No. Audio never leaves your device — there is no backend to send it to.
</details>

<details>
<summary><b>Why don't I hear tab audio in the transcript?</b></summary>
<br/>
When the share dialog appears, make sure you <b>tick “Share tab audio”</b> (Chrome/Edge). Without it, only video is captured.
</details>

<details>
<summary><b>Firefox says system capture is unavailable — what do I do?</b></summary>
<br/>
Some Firefox builds don't expose <code>getDisplayMedia</code>. Switch to the <b>Microphone</b> source, or use Chrome / Edge on desktop.
</details>

<details>
<summary><b>How long does the first transcription take?</b></summary>
<br/>
The first run downloads and caches the Whisper model. After that, inference is local and much faster.
</details>
