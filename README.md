## 🎬 What is this?

A **single-page, zero-backend caption studio** that lives entirely in your browser tab.

| Input | Engine | Output |
|:--|:--|:--|
| 🎙️ **Microphone** | Web Speech API | Instant captions — zero model download |
| 🖥️ **System / Tab audio** | Whisper (`@xenova/transformers`) in a Web Worker | Live captions **+** chunked WAV archive |
| 📁 **Uploaded file** | Whisper (WASM) | Word-level karaoke captions, styled like ASS |

> **Secure context required.** Open via `https://` or `http://localhost`.
> GitHub Pages is HTTPS, so you're fine — `file://` won't work.

```text
   ┌──────────┐    ┌────────────────────┐    ┌──────────────┐    ┌──────────┐    ┌────────┐
   │  Source  │ →  │ Capture (PCM@rate) │ →  │ WAV chunks   │ →  │ Whisper  │ →  │ Export │
   │ mic / tab│    │  getDisplayMedia   │    │ ~10 s each   │    │ 16 kHz   │    │ 4 fmt  │
   └──────────┘    └────────────────────┘    └──────────────┘    └──────────┘    └────────┘
                                                  │                                    │
                                                  └──────► full-session archive ◄──────┘
